# PenguinK's Music Macro Pad
Music Macro Pad project for Hack Club's Blueprint
<img width="1920" height="730" alt="Music Macropad" src="https://github.com/user-attachments/assets/2287d4cc-4b24-40ca-98fd-fe004f291baf" />

### Inspiration

I wanted to create a macropad for quickly controlling my music, skipping tracks, changing the volume or muting.

### Challenges

This was my first time using KiCAD and Fusion360. I struggled a bit creating the case, understanding QMK and with the implementation of an encoder and an OLED screen. But, in the end, I'm proud of how it turned out.

### Specifications

BOM:
- 3x Cherry MX Switches
- 1x EC11 Rotary Encoder
- 1x 0.91" 128x32 OLED Display
- 5x M3x16mm screws
- 4x Blank DSA Keycaps
- 1x XIAO RP2040
- 1x Case (2 Printed parts and a printed knob)

Firmware:
- QMK
